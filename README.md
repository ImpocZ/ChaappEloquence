# ChaappEloquence
## Hlavní myšlenka

Cílem je vytvořit chattovací aplikaci, která by navázala na můj velmi amatérský pokus v 2. ročníku.
Hlavní je vytvořit aplikaci s mnoha místnostmi, které by sami uživatelé mohli tvořit a upravovat.
Chtěl bych tam mít i hovorovou komunikaci, autentizace při přihlášení a možnost hraní hudby v místnostech, ať už general, nebo specifické vytvořené uživateli.
Dodatečné funkce jsou video hovory, kontrola hovorů, gify a nahrávání vlastních fotek (rozpoznávání řeči)

### Technologie
Frontend - JavaScript, Tailwind CSS, React\
Vite pro správu.\
Prisma na ORM s PostgreSQL a Node.js\
Cloudinary jako úložiště imgs.\
YouTube IFrame API na hudbu\
Tenor API na gify\
Auth.js na přihlášení přes Google a Discord.\
Livekit SDK na hovory
